# PowerPoint-Shrinker
A PPTX/PPTM file size shrinker that works by extracting the file and running the image files through a compressor, all wrapped up in a pretty little UI. Created during my time at Nissan. Uses ImageMagick for image compression.

Installation and Setup:

- Download the latest release
Portable Binary (will unzip dependencies on launch) **OR** Use the simple installer

How to use the tool:

- Click the "Browse" button to open a file picker, select the folder containing your PPT files (scanning is recursive)
- Select what files you want to compress and the compression level
- Click "Compress Checked" to start running the compression
- Say "wow this is cool"
