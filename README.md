# PowerPoint-Shrinker
A PPTX/PPTM file size shrinker that works by extracting the file and running the image files through a compressor, all wrapped up in a pretty little UI. Created during my time at Nissan. Uses bundled ImageMagick for image compression.

## **Installation and Setup**

- Download the latest release.
- For the easiest setup, use the **Installer**.
- Alternatively, use the **portable version**. On first launch, it will automatically extract all required files.

## **How to Use**

1. Click **Browse** and select the folder containing your PowerPoint files.
   - Folder scanning is **recursive**, so files in subfolders will be included automatically.
2. Choose the files you want to compress.
3. Select a compression level:
   - **High** – Maximum file size reduction
   - **Medium** – Balanced compression and quality
   - **Low** – Minimal quality loss
4. Click **Compress Checked** to start the compression process.
5. Watch your PowerPoint files get shrunked

## **Advanced (Admin) Options:**

Checking the Admin box will allow you to use some more advanced options such as opening the unzipped files whilst in progress, deleting all the backups, removing the Small_ prefix, CSV report files and other logs. Not recommended for standard users!
