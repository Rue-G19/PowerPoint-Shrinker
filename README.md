# PowerPoint-Shrinker
A PPTX/PPTM file size shrinker that works by extracting the file and running the image files through a compressor, all wrapped up in a pretty little UI. Created during my time at Nissan. Uses bundled ImageMagick for image compression.

Installation and Setup:

- Download the latest release
Portable Binary
**OR**
Use the Installer

How to use the tool:

- Click the "Browse" button to open a file picker, select the folder containing your PPT files (scanning is recursive)
- Select what files you want to compress and the compression level (High, Medium, Low)
- Click "Compress Checked" to start running the compression
- Say "wow this is cool"

Advanced (Admin) Options:

Checking the Admin box will allow you to use some more advanced options such as opening the unzipped files whilst in progress, deleting all the backups, removing the Small_ prefix, CSV report files and other logs. Not recommended for standard users!
